# Third-party content

Lessons under `src/content/books` are adapted from OpenStax textbooks (CC BY 4.0 or CC BY-NC-SA 4.0 depending on the book; the
licence is stored in each book's `toc.json` and shown on every lesson and on `/credits`). "Global notes" under
`src/content/extra` are shortened Wikipedia extracts (CC BY-SA 4.0). Course lists under `public/courses` come from the
EbookFoundation free-programming-books repository (CC BY 4.0) and from public catalogues (links only).

Because some of this material is NonCommercial/ShareAlike, do not sell this app or its content. The application code itself has no
licence file yet, so all rights in the code are reserved by its author until one is added.
